体活恢复速度计算器

根据角色等级、健身术和养生之道等级，计算体力活力上限，以及无海马和有海马两种状态下的恢复速度。

工具说明

梦幻西游体力活力恢复速度计算器用于根据角色等级、健身术等级和养生之道等级，快速估算体力与活力上限，以及无海马和食用海马两种状态下的恢复效率。

参数说明

角色等级

角色等级参与体力上限、活力上限和每 5 分钟恢复值计算。有效范围为 1 级到 175 级。

健身术等级

健身术只影响体力上限，不影响活力上限。有效范围为 0 级到 160 级。

养生之道等级

养生之道只影响活力上限，不影响体力上限。有效范围为 0 级到 160 级。

计算方式

上限公式

  • 体力上限 = 50 + 角色等级 × 5 + 健身术等级 × 4
  • 活力上限 = 50 + 角色等级 × 5 + 养生之道等级 × 4

无海马恢复

  • 单次恢复值 = 向下取整(上限 × 1%) + 向下取整(角色等级 × 2%) + 2
  • 每小时恢复值 = 单次恢复值 × 12

海马恢复

  • 使用海马后，体力和活力各立即增加 50 点
  • 海马持续 3 小时，期间每 5 分钟恢复值翻倍
  • 海马单次恢复值 = 基础单次恢复值 × 2
  • 海马每小时恢复值 = 基础每小时恢复值 × 2
  • 海马 3 小时总恢复 = 50 + 海马单次恢复值 × 36

使用说明

  1. 输入角色等级、健身术等级和养生之道等级
  2. 页面会实时计算体力上限、活力上限和每小时恢复值
  3. 左侧展示无海马结果，右侧展示食用海马后的结果

注意事项

  • 所有百分比计算统一向下取整，不进行四舍五入
  • 角色等级留空或输入 0 时，计算时按 1 级处理并回显为 1
  • 健身术等级和养生之道等级留空或输入 0 时，计算时按 0 处理并回显为 0
