工具说明

梦幻西游倒计时工具是一款面向游戏内各类冷却、刷新、周期性事件的集中计时工具。你只需在分类列表中点击需要的计时器，即可将其添加到自己的倒计时列表，所有计时器由统一的调度器管理，实时刷新剩余时间。

倒计时类型

类型说明示例
冷却（Cooldown）固定时长倒计时，结束后显示 00:00:00打坐、灵光宝匣
周期刷新（Interval）按固定间隔循环，需要设置第一次刷新时间帮派资材
每日（DailyPoints）每天固定时间点，到期后自动更新到下一个时间点师门、剑陵魔影
每周（Weekly）每周固定时间，到期后自动更新到下一周相同时间帮派迷宫

使用方法

  1. 在下方分类中找到需要的计时器，点击卡片即可添加到”我的倒计时”列表
  2. 如果计时器需要初始化参数（如周期刷新需设置第一次时间），会弹出设置窗口
  3. 添加成功后，倒计时会自动开始并每秒刷新
  4. 每张计时器卡片会根据配置显示可用操作，支持重新开始、编辑（仅需要初始化的类型）、删除
  5. 所有计时器数据自动保存在浏览器的本地存储中，关闭页面后重新打开不会丢失

注意事项

  • 倒计时数据仅保存在当前浏览器的本地存储中，清除浏览器缓存会丢失数据
  • 冷却类型倒计时结束后显示 00:00:00，点击”重新开始”即可重新计时
  • 每日/每周类型计时器会在超过时间后自动更新到下一次时间
  • 周期刷新类型计时器在设置第一次时间后，会自动按间隔循环计算
