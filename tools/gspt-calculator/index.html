工具说明

普陀山固伤计算器用于还原 collections/putuo 目录下原始 HTML 的普陀山固伤公式。输入五行法术技能、人物等级、敏捷、法修、秒怪个数和各类加成后，可实时查看当前条件下的总伤结果。

参数说明

基础参数

  • 五行法术技能：决定基础伤害段的核心数值
  • 人物等级：参与行云流水孔位加成折算
  • 敏捷：按原始脚本的 70% 折算进基础值
  • 自身法修等级：提升最终伤害
  • 对方法抗等级：抵消法修，得到有效法修
  • 秒怪个数：影响普陀固伤目标系数，仅支持 1-6

伤害与加成参数

  • 固伤灵饰加成：直接加到基础值
  • 固伤符石加成：按当前法修倍率折算后加入最终结果
  • 神木符：直接加到最终结果
  • 经脉选择：借灵 会启用武器伤害折算，推衍 会固定额外增加 50 点
  • 武器伤害：只有选择 借灵 时生效，按原始脚本的 24% 向下取整后参与计算

附加设置

  • 行云流水件数：支持 0 件、1 件、2 件
  • 第 1 件孔位 / 第 2 件孔位：2 孔、3 孔、4 孔 分别按人物等级的 25%、33%、50% 折算并向下取整
  • 阵法选择：支持 其他、雷阵、天阵

计算方式

基础值

  • 基础值 = 五行法术技能 × 3 + 50
  • 加上 向下取整(敏捷 × 0.7)
  • 加上 向下取整(人物等级 × 第 1 件孔位系数)
  • 加上 向下取整(人物等级 × 第 2 件孔位系数)
  • 加上固伤灵饰加成
  • 加上 向下取整(武器伤害 × 0.24)

系数与结果

  • 有效法修 = 自身法修等级 - 对方法抗等级
  • 目标系数：1 个 = 1.00，2 个 = 0.90，3 个 = 0.80，4 个 = 0.70，5 个 = 0.60，6 个 = 0.55
  • 阵法倍率：其他 = 1，雷阵 = 1.2，天阵 = 1.15
  • 阵法后结果 = 向下取整(向下取整(基础值 × 目标系数) × 阵法倍率)
  • 最终伤害 = 向下取整(阵法后结果 × (1 + 有效法修 × 0.02)) + 有效法修 × 5 + 向下取整(固伤符石加成 × (1 + 有效法修 × 0.02)) + 经脉附加 + 神木符

使用说明

  1. 先输入五行法术技能、人物等级、敏捷和秒怪个数
  2. 再补充法修、法抗、灵饰、符石和神木符
  3. 如有借灵、推衍或行云流水，再在附加设置中选择对应配置
  4. 页面会实时输出伤害结果，并展示关键中间值

注意事项

  • 所有小数处理统一向下取整，不做四舍五入
  • 人物等级留空或输入 0 时，会自动回填为 1
  • 选择 推衍 或 未点 时，武器伤害输入会自动禁用并清零
