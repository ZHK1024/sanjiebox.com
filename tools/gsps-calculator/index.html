工具说明

盘丝固伤计算器用于模拟计算逻辑盘丝天罗地网伤害，输入人物等级、秒的技能、面板伤害、法修、阵法和各类附加伤害后，可同时查看普通秒伤与有粘附秒伤的三目标结果。

参数说明

基础参数

  • 人物等级：角色人物等级
  • 秒的技能：师门技能等级,影响基础值和副目标系数
  • 法术修炼：直接提高最终输出数值
  • 怪物抗性：会从法术修炼中扣除，得到有效法修

伤害参数

  • 面板无符伤害：角色当前面板伤害基础
  • 武器伤害、灵饰伤害、头盔太阳石、伤害符、试剑石：都会影响最终秒伤
  • 灵饰固伤：会直接提升固伤表现
  • 命中符：提升面板伤害, 间接提升秒伤
  • 神木符：直接提高最终伤害结果

附加设置

  • 阵法加成：天阵 20% 加成、雷阵 1/2/3 号位 15% 加成
  • 孔装加成：孔装符石组合会直接提升最终伤害
  • 符石加成：原始 HTML 中保留了该字段，但脚本未把它纳入最终公式，本工具保持相同行为

提升盘丝秒伤

  • 提高技能等级：技能等级越高，主目标和副秒伤通常都会更高
  • 提高法术修炼：法修越高，最终伤害提升越明显
  • 降低怪物抗性影响：面对高抗目标时，实际伤害会被压低
  • 提高面板与附加伤害：武器伤害、灵饰伤害、太阳石、伤害符、试剑石都会带来增益
  • 补足灵饰固伤与神木符：这两项对固伤结果也有直接帮助
  • 选择天阵：天阵伤害加成 20%, 且克制怪物的普通阵法, 提升 5%.

使用说明

  1. 先输入人物等级、技能等级和面板伤害
  2. 再补充法修、阵法、孔装和各类附加伤害
  3. 页面会实时输出普通秒伤和有粘附秒伤结果
  4. 所有输入会保存在浏览器本地，下次打开页面会自动回显
